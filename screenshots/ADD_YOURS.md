
The app uses your **live webcam**, so screenshots will reflect your own
environment. To capture them:

1. Run the app locally (`node server.js`) or open the live demo.
2. Allow camera access and click **ENTER THE RIFT**.
3. Use your OS screenshot tool to capture key moments:

| File | What to capture |
|------|-----------------|
| `start-screen.png` | The "ENTER THE RIFT" start screen |
| `tear-open.png` | The rift torn wide open between your fists |
| `skeleton.png` | Hand-skeleton overlay on (press `H`) |
| `snap-shut.png` | The flash + shockwave rings right after releasing |

### Windows
- `Win + Shift + S` → drag to select → saves to clipboard
- `Win + PrtScn` → saves full screen to `Pictures/Screenshots`

### macOS
- `Cmd + Shift + 4` → drag to select → saves to Desktop

### Tips for good shots
- Dim the room lights a little so the rift's glow pops
- Tear wide and hold still for the "open" shot
- For the snap, release quickly and screenshot immediately

Save the PNGs into this `screenshots/` folder with the filenames above and
they'll automatically appear in the main README.
